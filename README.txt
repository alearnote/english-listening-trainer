English Listening Trainer - Windows setup

【初回セットアップ】
1. Node.js をインストールします（LTS版推奨）。
2. このフォルダ内の「.env.example」をコピーします。
3. コピーしたファイル名を「.env」に変更します。
4. .env をメモ帳で開き、
   OPENAI_API_KEY=ここにOpenAI_APIキーを入力
   の右側を自分のAPIキーに置き換えて保存します。
5. start.bat をダブルクリックします。
6. 初回は必要なパッケージが自動インストールされます。
7. ブラウザで http://localhost:3000 が開きます。

【使い方】
1. CEFRレベル・テーマ・英文の長さを選択
2. 「新しい問題」を押す
3. 「▶ 再生」で英文を聞く
4. 聞こえた英文を入力
5. 「採点する」を押す
6. 正解・日本語訳・AI解説を確認
7. 「もう一度聞く」または「次の問題」

【重要】
- .env ファイルは他人に送らないでください。
- OpenAI API はChatGPT Plusとは別料金です。
- 利用量に応じてAPI料金が発生します。
